## Question, method and evidence

Which decisions help an automated search finish with a better configuration when every arm has the same
budget? In Sweep 1, 3,274 of 4,999 replayed proposals repeated a configuration already evaluated. This
count measures how common repeats were and motivates testing whether skipping them improves the final
configuration. D.3 pairs arms on fresh instances, caps each campaign at 20 worker runs and 80 manager calls,
and evaluates the final configuration against its starting point on ten fresh seeds. A0R − A0 measures
skipping repeats and detectable no-ops under the default keep rule. A2 − A0R measures the noise-aware rule
with the same filter. A3 − A2 and A5 − A2 measure the forecasting arms' incremental effects. The paired
estimates, intervals and declared Holm decisions will determine which gains the manuscript can report.
The offline gate tests whether those forecasts improve one-step decisions on logged proposals.
