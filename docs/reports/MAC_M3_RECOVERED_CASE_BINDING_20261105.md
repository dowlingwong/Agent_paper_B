# M3 recovered-case and cache identity binding — 5 November 2026

AI-assisted (Codex). **Candidate for independent review, not production approval.** The existing OpenML replay STOP remains. No numerical replay, model, GPU, host or external network was used.

`bind_recovered_cases` composes the existing frozen-corpus and collector verification and `select_cases` recovery with the candidate 16-case shape checker. For every selected OpenML node it fingerprints a supplied source cache and a separately supplied candidate copy, checks pinned node files and dataset identity, and requires equal fingerprints. It binds those identities and the recovered configurations in a deterministic manifest labelled `offline_executability: NOT_ESTABLISHED`. Cache directories must have distinct, non-overlapping paths; that does not establish physically independent or private storage because files can be hard-linked or share other backing storage. The helper does not create or modify them. It does not prove that a cache is complete, that its origin is historical, that files stay unchanged after inspection, that any configuration runs offline, or that a Linux execution boundary works. A later full solution must verify immediately before and after use and address races and runtime closure.

Tests use all 16 actual recovered frozen-corpus configurations with deliberately synthetic cache files, plus synthetic one-case failures and cache mismatch/overlap failures. They read source records and pinned schemas only; synthetic hashes are not evidence about actual cache availability or equivalence. The original uncommitted candidate patch was copied to an isolated branch, leaving that worktree untouched. This candidate depends on the separately held `c3_env_replay.py` source and other candidate helpers on this M3 branch; it is not wired to production and must not be integrated into a branch lacking that dependency.

Remaining STOP: all 16 configurations must be shown executable offline under an accepted Linux boundary, with exact private cache copies, complete dependencies, no prohibited attempts, no cache changes, and configuration-dependent inputs accounted for. The implementer and independent reviewer must finish that non-numerical preflight and supervisor; if that cannot establish the requirement, the author must decide any protocol change. Separately, an authorized host operator must qualify the actual kernel and environment. Estimate: one or more engineering days plus review and host-dependent qualification.
