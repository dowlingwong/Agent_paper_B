### 2.1 The synthetic exam keeps the v1 line

`exam_synthetic.py` also used `budget_line`, so the first version of this change silently moved the frozen exam
template to the v2 line: `generate()` no longer matched the committed, sha-pinned `e0_v1.jsonl.gz` (`trackp_e0/v1`)
in any of its 4000 items, and the E6 probes built on the fly would have differed from E0 (found by the round-1 review;
the only guarding test already failed at the base for a gzip-byte reason). The exam now uses its own frozen copy of the
v1 line (`exam_budget_line_v1`), so `e0_v1` regenerates in content and the probes match E0. The exam template thus
keeps `Budget: trial b of W (W − b + 1 worker runs left before this trial)` while Track P prompts use v2. Moving the
exam to v2 would be a new E0 version (`trackp_e0/v2`, new file and sha, and a check that the E0 thresholds in
`r1/c3/rules/p3_rule_v2.yaml` still apply); that is the author's call (question W2-4).

v2 prints k without the v1 clamp: a ledger that showed k ≥ W before a trial would print "used 21 of 20" rather than
hide it; the W2-3 check should make this impossible.
