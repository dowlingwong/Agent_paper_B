# M11 D8 point statistics — synthetic-only core

**Independent review required; not a D8 gate or permission to read data.** PLAN R1-BX-D8 specifies across-node IQM of gap closed and per-node probability of improvement, ties one half, averaged across nodes. This standalone pure function unit computes those two point statistics from explicit numerical lists, using empirical 25%–75% IQM with fractional observation weights and equal node weight for probability. It does not read files, instantiate a data loader, calculate or exclude oracle-gap ratios, bootstrap, test Holm hypotheses, make a pass/fail decision, or alter an author decision. It is not wired to production readers or any gate.

Synthetic tests cover quantile boundary weights including odd node counts, ties, unequal node sample sizes, pairing and malformed/non-finite input. The first local run had **11 passed, 1 failed** because the test's manually written expected value for `[1, 2, 100]` was incorrectly 18; the actual fractional trimmed mean is 109/6. The expected value was corrected, and a new independent pytest temporary directory run gave **12 passed**. Both are local synthetic tests, not data analysis. No host, model, GPU, scientific evidence, or author-held files were accessed.

Actual D8 implementation still requires independently reviewed input/split and noisy-oracle provenance, dev-based exclusions, an independently qualified node-stratified 2,000-resample inference and Holm logic, a predeclared treatment of nonpositive resampled oracle denominators, reader coverage, and the author's separate exact code-SHA confirmation. If a choice is not fixed in the protocol, STOP and ask the author rather than silently choose. Existing time-boxed binding tests and prior review remain scoped; no sweep-2 label read or B.7 conclusion is authorized.
