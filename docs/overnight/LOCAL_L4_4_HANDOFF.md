# L4.4 pre-declaration scaffold handoff

AI-assisted. The template `docs/r1/templates/DEPLOYMENT_PREDECLARATION.md` identifies the fields the author must decide; it is not an adopted declaration or authorization. `python -m r1.predeclaration` hashes exact file bytes or verifies a supplied SHA-256 without writing the file. The digest must be recorded separately from the declaration itself.

Focused CPU-only tests are in `r1/tests/test_predeclaration.py`. The whole-suite comparison and independent review are pending; consult the L0 baseline before interpreting any differences. No contrasts, sample sizes, analysis choices, PLAN decisions or evidence authorization were filled in.
