AI-assisted (OpenAI Codex), 28 October 2026. Scope is the preserved B.1 batch and the author's specified B.2 split, not a claim of global seed isolation. No experiment was executed and no original artifact was modified.

1. **B.1 seed disjointness, within recorded and frozen-code evidence.** Each memory mode has 144 retained roots; the `(node, seed)` sets match the frozen collector `ccb4712` rule `100 + 10*k + sum(ord(node)) % 7`, for `k=0..17`. Root instance seeds range from 100 to 275 and do not include 7001–7010. A recursive scan of 11,915 retained numeric seed fields and array values in roots, events and trials, including manager seeds, found no 7001–7010. The collector creates `LocalWorker(train_seed=root.seed, split_seed=root.seed)` and the pinned harness `6adf385` passes these through the seed environment. Its theoretical verify-seed rule ranges from 1010 to 1401 for the declared budget, also outside 7001–7010; retained event and trial records show no verify calls. All 5,813 retained trial `training_seed` fields are null, however: no per-process environment snapshot proves every actual subprocess seed directly, and unrecorded temporary edits cannot be ruled out. The disjointness conclusion is therefore derived from frozen implementation and retained records, not asserted as a direct per-process manifest observation. The index's audit seed list is explicitly pending and is not proof of audit execution.
2. **B.2 task-level use.** The author clarified that 7006–7010 may be used for task-level joint-seed model retraining and evaluation in B.2, but not for C3/Track P model training, tuning or selection. The label block uses 7001–7005 and evaluation block uses 7006–7010. The 19 October pilot's use of 7001–7006 on other proposals was engineering, as disclosed in PLAN. B.2 has not been run.

Existing marker-based rejection is a partial guard, not a proof of global isolation; no broader claim is made.
