## Behavior and evidence boundaries

Opening a newly created file before applying the original mode can allow writing a configuration when the old copy-then-write path would have failed for a read-only copied file; conversely, a copied read-only parent directory can prevent new-file creation where writing an already-existing writable file was possible. The helper copies mode bits for an existing original but does **not** explicitly copy owner, timestamps, ACLs or extended attributes. The report's phrase that ownership is retained should therefore be read only as an unverified, site-dependent claim, not as demonstrated preservation of the source owner; neither source ownership nor eventual site behavior was checked. The old `copytree` also creates destination objects under the copying identity.
