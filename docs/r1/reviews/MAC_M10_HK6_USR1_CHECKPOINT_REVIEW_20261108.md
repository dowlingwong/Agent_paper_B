# HK6 cooperative USR1 checkpoint primitive: independent review

**ACCEPTED only as a cooperative, unintegrated runner-side primitive**, candidate `0bbec2980fc5fbfa4179f44881b482d711fd34c0`; this is not an accepted scheduler job, complete archive protocol or authorization. Runbook §1 requires USR1 forwarding, archival of the open unit and STOP on two cuts; this unit supplies only a main-thread signal flag and caller-invoked move of a quiescent owned unit. The caller must actually stop its own writers, bind identity/history, honor timing, report and exit; the helper does not do so, handle cut-twice or submit/retry.

The helper validates owned absolute non-symlink directories, requires same filesystem and nonoverlap, exclusively creates a numeric job directory, checks destination absence and source inode, then uses ordinary rename. On an error it retains the source/partial archive and refuses a second attempt in that instance. That check-and-rename is safe only for the disclosed cooperative-path assumption; it is not atomic adversarial NOREPLACE or an fsync/durability guarantee. No existing output deletion is implemented. Interruption/quiescence, shell forwarding, other process ownership, filesystem behavior and no-deletion policy require separate integrated review and site qualification.

Test-owned Python temporary cleanup is within the author's exception. Both files parse with Python 3.9 grammar; the execution interpreter was not established as 3.9.
