**Fresh independent review required; this is not the D8 gate.** PLAN R1-BX-D8 calls for 2,000 within-node instance resamples with a fixed seed and Holm over A3/A5; it does not identify a numerical seed, PRNG/version, finite-sample confidence-bound convention, or how to order two arms when each has the joint IQM and PoI criteria. Nor does it specify treatment of nonpositive resampled noisy-oracle denominators. The author's subsequent R1-BX-PROPOSED-CONFIRM accepts the listed numbers and tier pooling, while a separate code-SHA confirmation and preregistration remain mandatory. This unit does not resolve those choices.

`stratified_indices` is a generic within-node index generator: caller explicitly supplies the node sizes, draw count and random sampler; a single vector is reusable across paired quantities. It neither selects a seed nor implements an interval, node inclusion, normalization, oracle treatment, tier comparison, p-value calculation or analysis. For the *synthetic test only*, Python `random.Random(1234)` produces 2,000 reproducible draws; 1234 and this Python RNG are not a protocol decision. Any real implementation must bind its chosen fixed seed, generator, ordering, confidence convention and treatment of undefined resamples before analysis, and undergo independent statistical review.

`holm_two` is ordinary two-p-value Holm arithmetic with no alpha, arm ranking decision, joint-IQM/PoI p-value construction or pass/fail result. Supplying p-values alone does not implement the stated paired lower-bound conjunction, and no equivalence or complete inference claim is made. Invalid dimensions, sampler values and p-values are rejected. Local synthetic tests for these primitives and the accepted point-statistics core gave **26 passed** with an exclusive pytest base; no host, GPU, model, actual label or author-held files were accessed.
