# M11 D8-TEST: test-side STOP variants, with train+dev eligibility and fixed splits (15 November 2026)

**AI-assisted (Claude, Mac agent). Synthetic simulation only. Not an author decision. `gate.py` is not changed.**

This unit extends the 14 Nov eligibility-alternatives simulation (`M11_D8_ELIGIBILITY_ALTERNATIVES_20261114.md`,
accepted at `82923797`) to the open question **D8-TEST**. That simulation found that, with 2–6 test instances per
node, the per-node "any of 2,000 bootstrap test denominators ≤ 0" STOP drives P(STOP), whatever the eligibility rule.
Here the test-side options are compared on the **whole gate read**, not on P(STOP) alone: a rule that STOPs less is
useful only if the gate it then reads still discriminates. The author chose this extension on 15 Nov.

## 1. Model (declared)

- **Data, as on 14 Nov, plus an arm.** Per node and instance, d = U_oracle − U_A2 = μ + e and
  a = U_arm − U_A2 = g·μ + h, with e and h independent and sd 1.
  - μ is the ceiling gap in units of the per-instance sd. g is the arm's true gap closed: 0 (no effect) or 0.3.
  - All nodes share μ and g.
  - Data are normal; left-skewed e and h are a check (§3.4).
- **Layout.** T0 = 8 nodes × 18 instances. T1 = 10 nodes × 12, or × 6.
- **Fixed splits (train : dev : test).**
  - **P2 = 1/2 : 1/6 : 1/3**, recommended on 14 Nov: T0 9/3/6; T1 6/2/4 (× 12) or 3/1/2 (× 6).
  - **P3 = 1/3 : 1/6 : 1/2**, which moves instances to test at the same totals: T0 6/3/9; T1 4/2/6 or 2/1/3.
- **Eligibility.** R1 (the 14 Nov recommendation): paired z of d on train + dev ≥ 3 (and 6). δ_n is non-binding.
- **Gate read, as in `r1/c3/gate.py`, for the first-ranked arm.**
  - Per eligible node, gap closed G = mean(a)/mean(d) on the test instances.
  - IQM across eligible nodes, with the gate's fractional 25–75 % weights. These were checked equal to
    `gate._node_iqm` for 1–18 nodes.
  - PoI: the mean over all nodes of the share of test instances with a > 0.
  - Node-stratified bootstrap, 2,000 resamples, one shared index draw per node.
  - Pass iff the 97.5 % lower bound of the IQM is > 0 and that of the PoI is > 0.5. The real gate applies Holm over
    two arms. One arm at 97.5 % is its first step.
- **Test-side variants (the D8-TEST options).** All four also STOP when no node is eligible.

  | Variant | Rule |
  |---|---|
  | **V0** (current gate) | STOP if an eligible node's point test denominator mean(d) ≤ 0, or any of its 2,000 resampled denominators is ≤ 0 |
  | **V1** (point STOP, strict bootstrap) | STOP only on a nonpositive point denominator. A resample in which any eligible node's denominator is ≤ 0 counts as IQM\* = −∞: it can only lower the bound, and nothing is dropped |
  | **V1n** (point STOP, node-level bootstrap) | As V1, but only that node's G\* is set to −∞. It stays in the IQM, whose trimming may discard it |
  | **V2** (tier-pooled denominator) | Each node's gap is divided by its tier's pooled denominator, the mean of mean(d) over the tier's eligible nodes. STOP if a tier's point or any resampled pooled denominator is ≤ 0 |

- **Option "more test instances".** This is the split P3, at fixed totals.

## 3. Reading

1. **Under the current rule (V0) the gate is almost never read where it matters.**
   - With R1 z ≥ 3, P(STOP) is 0.94–0.99 up to μ = 1.5 under both splits. Nearly all of it is the test-side bootstrap
     STOP.
   - The power at g = 0.3 is ≤ 0.05 up to μ = 1.5.
   - This confirms the 14 Nov reading, now on the gate's verdict. A better eligibility rule only moves P(STOP) from
     "no node eligible" to the test side.
2. **Moving the STOP to the point denominator (V1/V1n) removes most STOPs.**
   - P(STOP) falls to 0.13 (P2) and 0.04 (P3) at μ = 1, and to about 0 from μ = 1.5.
   - What is left at μ = 0.5 is genuine: an eligible node whose point test mean is ≤ 0.
   - Two ways to treat a resample whose node denominator is ≤ 0:
     - **V1** keeps the "nothing is dropped" principle by failing the whole resample. With 2–6 test instances that
       happens often, so the lower bound collapses. Power at g = 0.3 is only 0.15 (P2) and 0.58 (P3) at μ = 1.5.
     - **V1n** fails only that node in that resample. The IQM's trimming of the lowest quarter can then absorb it.
       Power rises to 0.25/0.91/1.00 (P2) and 0.40/0.97/1.00 (P3) at μ = 1/1.5/2.
   - **The false-pass rate** at g = 0 stays ≤ 0.01 under V1n on normal data (≤ 0.022 on T1 × 6), below the nominal
     0.025.
   - **The cost of V1n is a departure from the gate's stated convention** ("no resample or node is dropped"). Within a
     resample a node can in effect be trimmed away because its denominator fell to zero or below. That is a
     preregistration choice for the author.
3. **The tier-pooled denominator (V2) STOPs rarely from μ = 1, and its power is close to V1n's.**
   - P(STOP) is 0.16 (P2) and 0.12 (P3) at μ = 1. Power is 0.39/0.93/1.00 (P2) and 0.47/0.97/1.00 (P3).
   - It still STOPs at μ = 0.5 (0.91), because a tier's pooled denominator can still go to zero or below in some
     resample.
   - **It changes the estimand.** Each node's gain is measured against its tier's average ceiling instead of its own,
     so a node with a small ceiling gap counts for less. R1-BX-D8 defines gap closed per node, so V2 needs a PLAN
     amendment. V1n keeps the per-node definition.
4. **Left-skewed check (P2, T1 × 12, 200 reps).**
   - V0 STOPs in 0.94–0.99 of reps at every μ.
   - V1n and V2 pass at g = 0 in up to 0.27 and 0.42 of reps. This is **not** a false pass of the test-side rule.
     With left-skewed noise, g = 0 sets the *mean* gain to zero while the *median* gain is positive, and both IQM
     and PoI respond to the centre of the distribution.
   - So under skew, "g = 0" is not a null for the gate's statistics. That is a property of the gate's estimand, not of
     the test-side variants.
   - It is worth noting for the confirmation draft: the gate tests a central or majority gain, not a mean gain.
5. **More test instances (P3 instead of P2).**
   - Under V1n, P3 gains power at μ = 1 (0.40 vs 0.25) and lowers P(STOP) (0.04 vs 0.13).
   - It costs 3 train instances per T0 node (6 vs 9) and 2 per T1 node.
   - Under R1, train + dev also shrinks (T0 9 vs 12), so eligibility is a little less sharp. The no-eligible STOP at
     μ = 0.5 is 0.09 vs 0.07.
   - Under V0, P3 does not help below μ = 2, consistent with the 14 Nov side calculation: the bootstrap STOP falls
     clearly only from about 12 test instances.
6. **z ≥ 6 instead of z ≥ 3.** It adds no-eligible STOPs at μ ≤ 1 (0.35–0.38 at μ = 1) and lowers power under every
   variant. Nothing in these results argues for raising the threshold once the test side is changed.

## 4. Recommendation (for the author to decide)

- **D8-TEST: V1n.**
  - STOP only when an eligible node's point test denominator is ≤ 0.
  - In the bootstrap, a resample in which an eligible node's denominator is ≤ 0 gives that node G\* = −∞. The node
    stays in the IQM, where its trimming may discard it. No node or resample is removed from the computation.
  - It keeps R1-BX-D8's per-node gap closed. Its power is close to V2's, and its false-pass rate stays below nominal on
    normal data.
  - Disclose it as a preregistered convention that replaces "a resampled test denominator ≤ 0 … is a STOP".
  - V2 is the alternative if the author prefers to change the estimand rather than the bootstrap convention. V1 is the
    strict reading, at a large power cost.
- **D8-R1: R1, train + dev, z ≥ 3**, as on 14 Nov. Under V1n the provisional caveat of 14 Nov is resolved: z ≥ 3 no
  longer raises P(STOP).
- **Split: lean towards P3 = 1/3 : 1/6 : 1/2**, if gate power at μ ≈ 1 is the priority. Keep P2 = 1/2 : 1/6 : 1/3 if
  Track P training instances are the binding constraint.
  - P3's tier test floors are **T0 ≥ 9; T1 ≥ 6** at about 12 instances per node, and **≥ 3** at about 6.
  - P2's are T0 ≥ 6; T1 ≥ 4 or ≥ 2.
  - Both are fixed proportions, as Q4 (d → c) asks. Under R1 eligibility depends only on train + dev, not on how they
    divide.
- **For the confirmation draft:** under skewed differences the gate's IQM and PoI test a central (median-like) gain,
  not a mean gain (§3.4). The D8 wording should say which one is meant.
