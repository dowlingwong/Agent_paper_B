# M3 seccomp notification component candidate — 5 November 2026

AI-assisted (Codex). **Incremental, unreviewed; not an executable replay boundary.** Production OpenML replay remains STOP. This candidate implements a Linux x86-64 seccomp classic-BPF program and the primitives to install a user-notification listener, transfer the listener to a trusted parent via a preopened private socket, and persist a notified syscall before writing `1` to a preopened delegated `cgroup.kill` descriptor. Any monitor read or audit error also attempts cgroup kill. The bootstrap FD exemption is restricted to `sendmsg` on the preopened handoff FD; its safe use requires all other inherited sockets to be closed and the channel to be closed before untrusted exec.

The filter rejects non-x86-64 and x32 syscall ABI values, notifies for the enumerated network, IPC and escape syscalls, and traps namespace-creating `clone` flags. It permits ordinary clone and other unlisted syscalls. The design requires a separately reviewed, complete syscall and architecture policy; the present allow-by-default list is **not certified complete**, and it does not itself enforce filesystem, namespace, capability, process supervision, or descriptor restrictions. The code has no production launcher or replay caller. It does not prove the handoff FD cannot be reused to reach an external socket absent those additional boundaries, or that supervisor death kills all descendants.

Nine Mac-local CPU tests emulate the generated BPF instructions and inject monitor/handoff I/O. They check listed syscall traps, wrong architecture and x32 kill, clone flags, handoff descriptor count, audit-before-kill, short audit writes and kill on receive/write/fsync failure. **No filter was installed and no real Linux seccomp/cgroup/namespace/worker process was run.** These tests cannot validate kernel constants, ioctl ABI, seccomp inheritance, notification ordering, crashes, cgroup semantics, policy completeness, or actual host capabilities. No server, outbound network, model, GPU, or experiment was accessed.
