## Why one model is enough here

R1-HOST-FREE requires one model per instance, not one model per campaign family. The D.3 pre-declaration
revision 4 §11 asks for the smoke on **each GPU model that will serve D.3**; this proposal names the
only model that can serve it now. Ada is excluded on a factual readiness gap (model and runtime), not
on a preference. If Ada is prepared later, its smoke is a separate, additive unit and changes no
TASL-2 row; D.3's paired design would then keep each instance on the model that served its arms.
