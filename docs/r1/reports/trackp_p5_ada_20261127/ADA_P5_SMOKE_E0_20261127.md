## Why this is a STOP, and what it is not

The head-fit block also differs strongly (Ada head-fit test RPS `0.01692` vs reference `0.04284`), which points
to code drift between paper `8e13e77` (the TASL-7/H200 reference) and current `c80f83bc`, not to the Ada card or
venv. The smoke proves the runtime and kernel bindings; the metric comparison cannot separate code drift from a
runtime difference. Per the comparator, a miss is a STOP for the author; the phase-1 note's `ada_smoke_e0:` line
must not cite this run as an equivalence.
