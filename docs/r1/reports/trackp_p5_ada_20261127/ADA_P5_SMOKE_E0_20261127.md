## Why this is a STOP, and what it is not

The head-fit block also differs strongly (Ada head-fit test RPS `0.01692` vs reference `0.04284`). The cause is a
**recipe change**, R1-E0-HEADFIT: paper `8e13e77` (the TASL-7/H200 reference) fits the head with AdamW and starts
LoRA from the fitted head, while current `c80f83bc` uses the descriptive L-BFGS head fit and restores the fresh
head (`471f93f7`, `52b527b9`). This is not a like-for-like runtime comparison. The smoke proves the runtime and
kernel bindings; the metric comparison cannot separate the recipe change from a runtime difference. Per the
comparator, a miss is a STOP for the author; the phase-1 note's `ada_smoke_e0:` line must not cite this run as an
equivalence.
