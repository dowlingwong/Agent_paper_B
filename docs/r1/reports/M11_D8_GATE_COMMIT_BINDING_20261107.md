# M11 D8: bind the gate to committed HEAD

AI-assisted (Codex); candidate pending independent review. The accepted D8 guard compared PLAN bytes with `HEAD:docs/r1/PLAN.md`, but calculated the referenced gate SHA directly from the worktree. A future committed author row could therefore name the SHA of an untracked gate file or an uncommitted replacement, without that gate code being committed. This candidate fixes that bounded gap: it snapshots the HEAD object ID; checks both authority entries are committed regular-file blobs and neither checkout path is a symlink or resolved alias; reads both blobs from that commit; compares them to the checkout files; checks the gate SHA in the decision row; and rechecks HEAD after those checks. Missing objects and mismatches STOP. The existing sealed-path check precedes file access.

Ten synthetic tests passed using mocks for all git and file operations, bytecode and pytest cache disabled, and a new pytest base (`/private/tmp/m11-d8-binding-test-20261107-r3`). Tests cover the committed, untracked and dirty gate cases, dirty PLAN, changing HEAD after checkout file reads, committed and checkout symlinks, and a negative decision. No label, model, experiment, server or GPU was accessed. Existing integration tests were not run: some deliberately remove files in conflict with tonight's no-deletion constraint.

This is not the complete D8 gate or a D8 decision. Git commit ancestry and file matching do not authenticate the author against a repository writer, nor protect against all concurrent filesystem mutation after the check; these remain process/review assumptions. The existing row parser accepts a negative sentence containing the correct SHA; a nonempty cell and matching digest alone cannot establish an affirmative author decision. This candidate therefore deliberately STOPs even for a structurally matching row until an actual author decision's semantics can be independently reviewed and the guard updated. Unblock: author supplies the D8 confirmation after the gate is reviewed; an engineer and independent reviewer then establish and implement a faithful parser for those actual words. Effort is bounded review and code/test work after the decision, with exact time unknown. The gate code is currently absent and the confirmation row has not been supplied, so sweep-2 analysis remains STOP. Gate implementation, verified split/noisy-oracle provenance, inference review and the author's confirmation are still required; generic protected train-reader coverage remains separately scoped. No author-held files were edited.

The final HEAD recheck is after the checkout file reads and structural decision check. It does not make subsequent analysis atomic or prevent changes after the check; stable checkout operation remains a process assumption.
