## 2. The (b2) bound as implemented

For each arm, with a = U_arm − U_A2 and d = U_oracle − U_A2 per test instance of an eligible node j:
- G_j = mean(a)/mean(d), the v2 gap closed;
- se_j² = [var(a) + G_j² var(d) − 2 G_j cov(a, d)]⁺ / (n_j mean(d)²), with ddof 1 (`_node_se`, the simulation's
  `node_se`);
- θ̂ = IQM(G), and ŝe = √(Σ_i w_i² se_(i)²) with the IQM weights on the ascending order of G;
- in each resample: G*, se* the same way, IQM* and se*(IQM) on the resample's own order;
  t* = (IQM* − θ̂)/se*(IQM);
- t* counts as +∞ if the resample has a nonpositive eligible-node denominator, se*(IQM) is not > 0, or t* is not finite;
- the lower bound at level L is θ̂ − q_L(t*)·ŝe, with q_L = `numpy.quantile(t*, L, method='linear')`; if ŝe = 0 the
  bound is θ̂ (the simulation's rule).

**Agreement with the simulation.** `r1/tests/test_d8_gate_synthetic.py::test_b2_bound_equals_the_simulation_code`
reimplements the simulation's lines on the gate's data and index draws, and checks equality of t* and of the bound
(relative 1e-9) for nine tables (normal, left-skewed, t3; μ 0.5–6), two of them with positive bounds and no screened
resample. A wider run
(`reports/m11_d8_gate_v3_20261116/agree.py`, output `agree_output.json`, NumPy 2.4.4): 444 bound comparisons on 111
tables, all 444 pass/fail decisions identical, largest relative difference 2.2e-16. Nine tables were skipped because
the gate STOPs on a nonpositive point denominator (V1n), as the simulation does.

## 3. Conventions the rows do not fix (preregistration candidates)

1. **+∞ is held as 1e12** (`TSTAR_INF`), as in the simulation (`BIG`). The bound then equals the simulation's
   bound. With a nonnegligible ŝe, more than (1 − L) of screened resamples drives the bound far below 0, as a literal
   +∞ would. The two differ only when ŝe is of order 1e-12 of the bound. That happens, for example, with constant node
   data, where rounding leaves var > 0 at about 1e-18. A first draft used a literal +∞; with it, such near-degenerate
   tables failed where the simulation passes, so the sentinel was kept.
2. **ŝe = 0 ignores the screened resamples.** This is the simulation's rule (`prim = theta > 0 if se_hat == 0`), kept
   as declared. It arises when every IQM-weighted node has zero within-node variance; a node whose resamples are
   screened but which the IQM trims (weight 0) does not add to ŝe. A test documents it
   (`test_se_zero_ignores_screened_resamples_as_in_the_simulation`). It cannot arise with continuous utilities.
3. **Ties in G** are ordered by a stable sort over sorted node ids. The simulation used NumPy's default sort, which is
   not stable on every platform (the review found it unstable for small tied vectors on this host), so with exactly
   tied G the simulation's ŝe depends on the platform and can differ from the gate's. Without ties the two agree.
4. **Ranking for Holm** keeps v2's structure: the first-level pass test first, then a composite tail share, then the
   fixed order A3, A5. For (b2) the IQM tail share is the share of resamples with t* ≥ θ̂/ŝe (the smallest one-sided
   level at which the bound would reach 0). As in v2, the ranking cannot change the verdict or the set of passing
   arms.
5. **Split check.** The gate requires the declared split to be exactly P3, and train, dev and test ids to be disjoint.
   At the design sizes P3 is exact (T0 6 : 3 : 9, T1 4 : 2 : 6), so a node at its design size whose counts differ is
   listed under `off_split` (for example a P2 split labelled P3). Off-size nodes are listed under `off_design_size`;
   no row fixes how their counts round. Neither list is a STOP.
6. **Train + dev z.** Train and dev must each be nonempty, so n ≥ 2 and v2's `dev_n` reason has no counterpart. With
   sd(d) = 0, z is +∞ if mean(d) > 0 and the node is ineligible otherwise; z = 3 exactly is eligible.
7. **Reported fields** added: per node `n_train`, `n_dev`, `n_total`, `design_instances`, `test_floor`, `train_dev_z`,
   `z_sd_zero`, `se_gap_closed_<arm>`, `resamples_nonpositive_denominator`; per arm `se_iqm_gap_closed`,
   `tstar_quantile`, `resamples_with_infinite_tstar`; top level `gate_version`, `below_test_floor`, `off_design_size`,
   `off_split`.
8. **Ties in the utilities (disclosure).** D8-SKEW and D8-PASS simulated continuous utilities, with no ties. The gate
   counts a PoI tie as ½ (R1-BX-D8), where the simulation's `a > 0` counted it as 0, and exactly tied G fall under
   item 3. If the sweep-2 utilities are discrete enough to tie, the calibration evidence does not cover those ties.
