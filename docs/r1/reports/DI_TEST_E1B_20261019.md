## Measures and contrasts

For each branch, use only trials with budget index greater than the point. Summarize the next one, next three, and all remaining trials. Primary outcomes are mean recorded delta relative to **that branch’s own incumbent**, and fraction of deltas greater than zero. These are single-campaign noisy values, not audited proposal means. Later incumbent changes remain part of the observable trajectory.

For scalar outcome m, the cross-action distance at a point is the mean of `abs(m_continue,r − m_verify,r)` over repetitions. `D_changed` averages those distances over changed points; `D_unchanged` does so over unchanged points. The same-action baseline per point is the mean of `abs(m_continue,1 − m_continue,2)` and `abs(m_verify,1 − m_verify,2)`. The tables show D_null over all points and D_null restricted to changed points. **The primary excess over null pairs each changed point with its own null baseline**, avoiding a comparison of changed points against a different mix of histories. Also report signed verify-minus-continue differences to distinguish direction from distance.

Secondary outcomes are total variation between edited-key frequency distributions; mean signed log(new/old) for positive numeric edits; active-key novelty; active-configuration duplicate fraction; and fraction of delta exactly zero at recorded metric precision. Total variation is a distance directly; the other scalar distances use absolute differences. The signed log size uses natural logarithms, retains direction, and excludes categorical/zero/nonpositive edits rather than assigning an invented magnitude. The JSON records numeric-edit denominators. Active novelty requires a configuration different from both the incumbent and every previously evaluated active configuration; duplicates refer to previously evaluated active configurations, including discarded candidates before the fork. Replay starts from committed start_files, restores the snapshot incumbent at the point, applies the observed point decision, and then follows the branch. It never runs a worker. All digits constants are active. For the numeric ionosphere logistic model, C, max_iter, class_weight, scaler and model_type are active; tree-only keys and imputer are excluded, consistent with the D25/D28 logic and the ionosphere diagnosis.

A verify action spends four worker evaluations. Remaining branch lengths at points 4/8/12 are 16/12/8 for continue and 12/8/4 for verify. Therefore the all-remaining contrast has unequal horizons and includes a budget-composition effect. The next-one and next-three summaries have matching trial counts. The tables give equal weight to points, not to individual trials or longer branches; branch descriptive means give equal weight to each branch.

## Inference

Repetitions are averaged before inference. The permutation shuffles changed/unchanged labels **across whole points within a node**, preserving each node’s changed count, using 9,999 draws with fixed seed 20261019. One-sided statistics are mean paired excess over null in the changed subset, and mean changed cross-action distance minus mean unchanged distance. Their p values test whether the observed changed subset has unusually large distances/residual distances under label exchangeability. They do not by themselves test a zero population effect or provide randomized-intervention inference.

For intervals, resample instances with replacement within node and carry all their points together, using 9,999 draws. Replicates missing either subgroup are undefined and excluded; the generated table reports the valid count (9,988 here). Report percentile 95% intervals and both excesses in metric units; only mean-delta effects are divided by node sigma_d. Ionosphere has no changed points and no corresponding inference. Exclude it from the pooled value-relevant result, so the eligible pool equals digits. The table also repeats the digits mechanism diagnostics for that eligible pool; no apparently larger sample is claimed.

As an added conservative diagnostic rule, a primary comparison requires both excesses positive, both one-sided p values below 0.05 and both interval lower bounds above zero. Apply Holm adjustment to the maximum of the two p values for each of the six primary horizon/outcome comparisons. Secondary outcomes are exploratory, without multiplicity-adjusted claims. This rule and implementation are visible and deterministic; they were not preregistered. Neither adjustment nor cluster bootstrap repairs the nonrandom assignment of changed status or the small number of independent instances.

## Limitations and C4 / A7 decision

**Memory mode none is the main limitation.** The primary append_only_summary C3 proposer has no complete accepted committed branch dataset in this analysis. The preserved failed rerun-2 arm contains partial memory-on artifacts, but these were only inspected for Task 1 and were not substituted into this committed-data DI test.

There are only six changed unique points in four instances; only six digits instances exist overall. Changed status is selected by verification outcomes and correlates with state and candidate quality. Permuting it across heterogeneous histories is an exchangeability assumption, not random assignment. Every observed change is a promotion, so no conclusion is available about demotion. Verification alters the incumbent configuration and its recorded value, and the same relative edits can produce different deltas after that alteration. This diagnostic does not isolate feedback beyond incumbent configuration, nor show a memory mechanism. All-remaining comparisons additionally differ in budget and horizon. The original decoding has no seed, and same-action repetitions only estimate a limited nondeterminism baseline. No fresh-seed paired audits of these subsequent proposals are available; final-leaf audit summaries are not proposal-level audits. Lack of a scripted per-trial control further weakens causal interpretation.

Accordingly, the requested empirical distance criterion flags a memory-off deviation, while **the policy question remains undetermined**. Do not treat it as proof of the T4 conditional-law claim, a scientific acceptance result, or a mandate for A7. A memory-on paired diagnostic with controlled incumbent effects and audited values is needed before escalating the ladder.

## Deviations from the prompt

1. Removed the scripted control because its per-trial branch ledgers do not exist, per authorized addendum `bf52f5c`; no regeneration.
2. Defined changed from actual continue/verify records in both directions, per direct author authorization. All observed changes are promotions, not demotions.
3. Disambiguated D as absolute scalar distance (TV for keys) and retained signed effects; paired the null baseline at the same changed point. These definitions were unspecified originally.
4. Accounted for verify’s shorter remaining horizon instead of treating all-remaining samples as equal-length. Fixed next-one/next-three outcomes are the clearest comparisons.
5. Added explicit uncertainty/multiplicity criteria, while identifying label permutation as an exploratory exchangeability analysis rather than a causal DI test.
6. Replayed committed snapshots/start files without importing the harness. Historical escaped newlines in start_files are decoded only for parsing. Metadata and exact source hashes are retained.
7. The full r1/tests suite was not run: `autoresearch` is unavailable in the isolated analysis environment. Existing historical harness environments were not used for tests. The requested new test file passed five file-only tests, including a DI-holds fixture that does not reject and a shifted fixture that does.
