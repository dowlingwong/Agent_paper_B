## Attempts (all preserved, no deletion; each fixed before the next)

The unit's first real submissions found six wrapper bugs that the synthetic tests did not: (1) stale `--scratch`
argument; (2) pre-created empty `job_record.json` treated as a resume; (3) non-JSON-serializable torch `uuid`;
(4) llama.cpp does not print its version line at startup (`--version` query added); (5) r3 pre-created `out/` dir
broke the collector's `mkdir`; (6) transfer outputs switched to `out.tar`/`work.tar` so early STOPs do not hold the
job (S4-B1) while the collector can create its own dirs. The failed submit dirs are preserved as
`sweep2_pilot_s2c4_20261116_a.attempt{1..6}-*` on deepthought; the successful run is attempt 7. No data or jobs were
deleted; the failed attempts never produced labels.
