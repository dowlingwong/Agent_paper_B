## 1. P4 blocker — resolved by author row R1-S2C3-DRIVER (implementation; run still pending)

The frozen unit could not run off TASL because the unmodified B2 preflight hard-codes TASL-side state. Author row
**R1-S2C3-DRIVER** (`origin/author-decisions-20261116b` @ `025bfc16`) authorises a reviewed, declared-input,
TASL-independent ENGINEERING driver, and this branch implements it:

- `author_gate` Stage A inputs: the two TASL-absolute tables are shipped as declared sha256-pinned copies that are
  byte-identical to what `exam_b2_v2.json` binds (`00ab143d…`, `7152512…`); the shim only relocates the read path
  after the same sha256 check;
- `host_check`/`require_worker_host`: in replay mode the TASL host/work-dir pins are replaced by "must not run on
  TASL-2/TASL-7" + "out inside the declared job sandbox"; the B2 authorization note/config/GPU binding still gates the
  run, so the ENGINEERING check cannot silently become a TASL/EVIDENCE run;
- `out` rewrite: admitted by the replay-mode sandbox check;
- OpenML cache: shipped as the declared deterministic archive `S2C3_IN_openml_cache.tar.gz` and installed into the
  pinned harness clone at the exact path the campaign copies from (the path is gitignored by the pinned harness).

The driver proves the bypass is exactly the reviewed set: it runs the B2 gates twice with the same patched sources —
unshimmed (must report exactly the reviewed TASL refusals) and shimmed (must pass every gate) — before fetching the
model. An unexpected refusal is a STOP. The shim adds lines only to `r1/exam/runtime.py` and `r1/exam/campaign.py`, is
screened against trial/audit/scoring code, and both patched source files are byte-pinned.

Remaining steps for P4: independent review of `S2_C3_DRIVER.md` + the shim, `condor_submit -dry-run` by the operator
on the submit host, then the three ENGINEERING jobs (one per node) only after the author's sweep-2/EVIDENCE gate.
Until then P4 is **not claimed**.
