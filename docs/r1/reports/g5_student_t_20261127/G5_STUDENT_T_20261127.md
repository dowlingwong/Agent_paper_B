## 3. What σ means, and the choice made (level 2)

**What the Gaussian path means by σ.** σ̂_node (`noise_floor.t1_sigma_node: "t0_definition"`, D6-σ B) is
`dataset.noise_table`'s rule: the median, over material edits, of the **sample standard deviation** of the joint paired
differences. The soft-label width is s = σ̂_node/√k_label (R1-SOFT-SIGMA, `pooled_node`), the **sd of a k-seed mean**.
For a Gaussian, sd and scale are the same thing, so the docs never had to say which one σ̂ is.

**The docs on the Student-t.** E5 and R1-BX-REVISIONS (c) say only "uses a Student-t". `TRACK_P_POST_TRAINING.md` §3.4
says "integrate a Student-t … instead of the normal". That option was written with ν = pooled df (≈ 29), where the two
readings barely differ. Its formula y = Φ((e − μ)/s) − … suggests substituting T_ν for Φ with the same s, which would
make s the scale. The docs do not settle the question for ν = 5, so this is a level-2 point.

**Built: option A, σ̂ is the sd (`STUDENT_T_SCALE = "sd_matched"`).** The Student-t has location Δ_label/σ̂_node and
sd s, so its scale is s·√((ν−2)/ν) (0.775·s at ν = 5).
Why:
1. σ̂ is an sd estimate by construction, and s keeps that meaning on both paths.
2. Only the shape changes, not the spread. The arms' belief moments (`labels.moments`) and the A2 constants compare a
   Student-t node with a Gaussian node at the same variance.
3. ν > 2 is then required (the variance must be finite), which the validator enforces.
4. It is the conservative option the task card names.

| Option | Scale of the Student-t | Effect at ν = 5 | Status |
|---|---|---|---|
| **A: σ̂ is the sd (built)** | s·√((ν−2)/ν) | same variance as Gaussian; more mass in the outer bins and the centre, less in between | built, `sd_matched` |
| B: σ̂ is the scale (literal Φ→T_ν substitution of TRACK_P §3.4) | s | sd = s·√(ν/(ν−2)) = 1.29·s: every Student-t label is wider as well as heavier-tailed | not built |
| C: a robust scale (e.g. from a MAD of the paired differences) | from a new statistic | needs a new noise statistic and a decision on it | not built |

Changing A to B needs only `student_t_scale` and the constant. The tests pin A.

Effect at ν = 5, Δ = 0, k = 1 (z units, s = 1): Student-t mass in z > 3 is 0.005862 (Gaussian 0.001350), and in the
central bin (−0.15, 0.15] it is 0.145928 (Gaussian 0.119235).
