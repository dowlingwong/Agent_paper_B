# P.4 E0 same-code repeatability — Ada repeats within tolerance, TASL-7 does not

Task `compute/20261128-08`, PLAN **R1-P4-E0-REPEATABILITY** (`main` `2e8d089a`). ENGINEERING_ONLY (`DRYRUN`).
One repeat on each host, identical to that host's first same-code run: paper `c80f83bc`, the same E0 reference
config content, same data manifest `b963be2d…`, Kev-0.8B base, seed 0, stage `final`, fresh run directories.

**Result.** Ada is repeatable within the existing 10 % RPS tolerance (repeat vs first: RPS +9.66 %, both slopes
pass). TASL-7 is **not** repeatable within it (repeat vs first: RPS +26.13 %; slopes pass). The cross-host pair
also depends on which runs are compared: Ada first vs TASL-7 first is not equivalent (RPS +23.60 %), while Ada
repeat vs TASL-7 repeat is equivalent (RPS +7.46 %). Neither host is bit-identical run to run.

No criterion was changed or proposed here. The existing E0 criterion stays in force; a criterion change goes to the
author with this evidence. The P.4 phase-1 note and A5 SFT remain gated.

## Reading

The within-host TASL-7 RPS spread (26 %) is larger than the 10 % cross-host tolerance used by the E0 comparison, so
a cross-host RPS comparison at this near-1e-4 level is not stable across repeats. The repeat pair happens to pass;
the first pair does not. This is evidence about repeatability, not a re-reading of the first pair: the first TASL-7
reference (`p5_e0_ref_20261128/e0e`) and the first Ada run (`p5_20261127_b/e0e`) remain as recorded.
