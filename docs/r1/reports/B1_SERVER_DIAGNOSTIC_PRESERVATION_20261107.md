# B1 server diagnostics preservation — 7 November 2026

AI-assisted (Codex). Candidate, pending independent review. Real B1 writes GPU prelaunch occupancy and offload evidence under filenames containing the corresponding `LlamaServerInstance.record_path` stem and uses the existing `write_exclusive_json` helper. A later thinking-mode server instance therefore obtains distinct records, and a collision stops rather than replacing earlier evidence. JSON payload fields are unchanged. This is scoped to non-DRYRUN B1; Stage A, DRYRUN, and B2 retain existing paths and writers. In-repository source search found no consumer of the old occupancy/offload filenames; external consumers and operational scripts require separate review. The instance record name includes port and generation and is already used for server evidence, but its uniqueness and path stability are cooperative assumptions, not an adversarial filesystem guarantee. More `.json` names participate in the existing generation count on repeated starts, so later generation numbers can differ from legacy and must be disclosed.

Two pure in-memory unittest cases passed with `python3 -B r1/tests/test_b1_server_diagnostic_preservation_unittest.py`: actual AST-extracted diagnostic branches, simulated writers, two server identities, repeated-name refusal and unchanged non-B1 names. No actual diagnostic file, server, GPU, host, model or experiment was used. The first test attempt failed solely because the AST traversal returned the two branches in reverse order; the original test source is retained in `_to_delete/test_b1_server_diagnostic_preservation_unittest_initial.py` in this isolated worktree, and the second test uses order-independent assertions. The tests do not establish real filesystem exclusive creation, runtime paths, contents' scientific interpretation, STOP/freeze serialization, or complete no-overwrite coverage. The exclusive helper also rejects non-finite JSON values where the legacy writer did not; that difference fails closed and needs review. Site qualification and independent integration review remain mandatory; this patch does not authorize B1.
