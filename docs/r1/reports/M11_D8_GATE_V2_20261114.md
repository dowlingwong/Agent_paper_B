What this shows:
1. **The per-node STOP probability at a given true test z does not change.** The rule helps only by excluding low-z nodes before they can STOP the gate. Under normal differences with n_dev = 20 and all nodes at z = 5, P(STOP) falls from 0.52 to 0.22 (10 nodes); with nodes spread over z = 3–8 it falls from 0.90 to 0.12.
2. **A new STOP route grows: no eligible node.** With a small dev split (n_dev = 10), P(no eligible node) is 0.40 for 10 nodes at z = 5 and 0.90 at z = 3.
3. **A large dev split weakens the rule**: with n_dev = 60, dev z ≈ 1.7 × test z, so nodes at test z 4–5 pass it and P(STOP) returns to the old value (0.52 at z = 5).
4. **Left-skewed differences are not protected.** A small dev sample often misses the left tail, so its dev z overstates the true z (27 % of nodes at true z = 3 pass with n_dev = 10). P(STOP) stays at 0.66–0.94 for 10 nodes at z ≤ 6.

The answer's rule is implemented as stated. Whether these numbers call for a further change (for example a dev z threshold that depends on n_dev, or a different denominator rule) is the author's decision; it is listed as an observation, not a question requiring an answer before confirmation.

## 4. Implementation conventions (new or changed)

Numbering continues `M11_D8_GATE_20261109.md`:
- 4 (changed context): the denominator STOP is unchanged; "no eligible node" now also covers nodes excluded by dev z.
- 10 (changed): partial T1 is not a gate STOP (Q1); suites without a labelled T1 node are reported.
- **14 (new): dev z.** d = oracle − A2 per dev instance (the dev vectors are paired by position, as the gate already requires equal lengths); dev_z = mean(d) / (sd(d, ddof = 1) / √n_dev). n_dev < 2: ineligible (`dev_n`). sd(d) = 0: eligible on this criterion only if mean(d) > 0; dev_z is then reported as null with `dev_sd_zero` true. dev_z exactly 6 is eligible. Non-finite intermediate values raise `ValueError` (fail closed).
- **15 (new): no minimum test count** (Q4 not implemented).
- The environment string is recorded, not checked; only NumPy is checked (convention 1).
