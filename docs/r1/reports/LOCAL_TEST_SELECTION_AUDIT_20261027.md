Avoid broad collection until module import effects have been audited. Maintain an explicit allowlist of complete node IDs, not an assumed-safe remainder after only the exclusions above. The empty allowlist is the safe fallback where inspection is incomplete.
2. Derive the same allowlist from the common test identities at baseline and post-change. Compare the actual node IDs, parameter IDs, test and fixture source hashes and outcome categories, not only counts. Inspect differences in imported production paths and fixtures at both revisions; exclude newly unsafe or ambiguous paths from **both** sides. Record excluded, absent, skipped, collection-error and new tests separately. A source hash alone cannot prove identical transitive behavior. Do not use a permitted timeout as a substitute for preselection.
