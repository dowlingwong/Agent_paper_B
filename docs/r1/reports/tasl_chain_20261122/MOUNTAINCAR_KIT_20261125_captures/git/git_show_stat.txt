    trackg T1 expansion kit: isolated node mlgym_metamaze (R1-T1-NODE-EXPANSION candidate 3, MetaMaze)
    
    Port of R1-T1-NODE-EXPANSION candidate 3 ("MLGym MountainCarContinuous or MetaMaze") as an isolated Track G
    harness kit, based on mac-trackg-t1-tasl-20261121 @ c025f89a (accepted T1 TASL harness; contains the accepted
    isolation core 68cdd1a and fix 5403392e and the three accepted iso port kits).
    
    MountainCarContinuous (rlMountainCarContinuous) was checked first and rejected for a noise floor: an episode
    ends at the goal and the +100 bonus is paid once, so the return is a two-mode solved/not-solved statistic with
    no partial credit (U3 already recorded "tends to end solved or not solved, a poor fit for a noise floor"); an
    MLGym-PPO probe at the node's 1-2 min-class budget (2,000,000 environment steps) stayed wholly in the unsolved
    mode (per-episode returns -25..-217, mean -160, 0 solved).  MetaMaze's return is a graded count of goals
    reached (the goal re-draws on success and the episode continues; +10/goal over 199 frames): the same probe gave
    a graded validation return (mean 8.1, sd 12.3, range 0-50, headroom below MLGym's published baseline 15.7).
