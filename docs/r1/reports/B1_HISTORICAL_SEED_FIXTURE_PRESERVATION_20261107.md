# Historical seed test fixture preservation — 7 November 2026

AI-assisted (Codex). **Candidate; independent review required. No pytest execution is authorized by this change.** The historical-seed test now creates the initial ledger, source and outside fixture exclusively. Changes to the synthetic ledger or prompt source move the existing file into a newly and exclusively created UUID-named private subdirectory under the test-owned `_to_delete` directory, then create the replacement exclusively. This retains previous bytes and keeps the tests' intended provenance, relative-path, escape and seed assertions, subject to independent review. The ledger-change test still compares a retained source-bound original digest against changed ledger bytes.

The move uses Python `Path.rename`, not a kernel no-replace rename: absence of the destination depends on a freshly and exclusively created directory remaining private and unchanged by cooperating test processes. UUID collision fails the directory creation rather than selecting another name; external path replacement, malicious/same-UID concurrent mutation, or unsuitable parent ownership are outside this candidate. A write failure can leave the archived original and a partial new file; neither is removed. `_to_delete` itself is reused if already present, so this helper does not independently establish safe parents or the overall test environment. All original assertions still require validation by an independent reviewer; file metadata and timing are not guaranteed identical to in-place truncation.
