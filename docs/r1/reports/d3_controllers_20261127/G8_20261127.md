## Content (`r1/c3/accounting.py`, `r1/branch/matching.py`)

- **Replicate runs** (pre-declaration §5 "Run accounting"): `campaign_usage` counts the FIXR3/EGATE replicate runs
  recorded in a trial's `extra.control.replicates` (`replicate_entries`: role, j, seed, success, charged). A charged
  entry adds one worker run; a reused incumbent run (`charged: false`) adds none (`replicate_runs_reused`). Refused,
  fail closed: malformed entries, a candidate j = 0 entry (that run is the trial's own record), an uncharged
  candidate entry, a repeated (role, j), replicate entries on a trial whose worker did not run.
- **One W counter** (G1/G6 design §2.2): `ChargedRunCounter(W)` charges trial, verify and replicate runs one at a
  time; `require(n)` refuses a step before it starts when fewer than n runs are left (`UnfundableStep`); a charge
  beyond W raises `OverBudget` (a STOP, §10); `on_charge` is the per-run hook for the w = 5, 10, 15, 20 snapshots;
  `lookup(config, seed)` returns the latest run (failed runs too: never re-run).
- **Re-issued LLM calls** (R1-NO-TIMEOUT (1), §3.1 item 2): contract — the runner logs each re-issue as an
  `llm_call_reissued` event and only the call that returns creates its proposal event; `campaign_usage` never counts
  a re-issue (`reissued_llm_calls`, descriptive).
- **`table_ended_on`**: `ended_on` of an outcome row by the pinned analysis's rule (worker_runs iff runs = W; else
  llm_call_cap iff calls = cap; else no_fundable_candidate for FIXR3/EGATE; over W or cap → `OverBudget`).
- **`classify_worker_failure`** (§3.1, R1-CARD-SHARE (3)–(4)): host kill, reset, lost connection, walltime, no
  progress, server lost → infrastructure; invalid config and the two admitted runtime errors → the proposal's
  failure; a budget hit or OOM is infrastructure only if the card had another compute process at job start or end
  (an unrecorded count is refused). **§13 item 31 switch:** `CPU_SHARING_IS_INFRASTRUCTURE = False` as built; the
  alternative is implemented behind the flag and then requires the host's other processes at start and end.
- `CampaignUsage` gains three fields with defaults (`replicate_runs`, `replicate_runs_reused`,
  `reissued_llm_calls`); existing callers are unchanged.
