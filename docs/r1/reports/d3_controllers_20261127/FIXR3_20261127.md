## Content (`r1/c3/d3_replicate.py`, new)

- `Fixr3Engine(instance_seed)`, pre-declaration §5.4: a harness-free step engine. One step = one executed
  proposal, run on replicate seeds j = 0, 1, 2 (`replicate_seed`: j = 0 the instance seed, j ≥ 1
  `d3_analysis.replicate_seeds`, smoke seeds included), every run charged singly through the campaign counter
  (j = 0 as `trial`, j ≥ 1 as `replicate`). A step needs 3 runs and is refused before it starts with fewer left
  (`UnfundableStep` → `no_fundable_candidate`). First valid trial: three runs, kept without a test. Later: keep iff
  the one-sided Welch test of mean(candidate) > mean(incumbent) gives p ≤ 0.05, the incumbent's three runs being its
  own runs as a candidate (no incumbent run is ever made). Any failed replicate → `failed_invalid`, charged for the
  runs used, the rest not run; a failed first trial leaves the next proposal as the first trial. Both variances
  zero → no keep, counted (`zero_variance_cases`). Memory line value (§13 item 15): the mean of the successful
  candidate replicate metrics (`display_metric`). r = 3 and α = 0.05 are fixed (another value is refused).
- `welch_one_sided`: the statistic, Welch–Satterthwaite df and p (scipy's t), with exact variances
  (`statistics.variance`), so identical runs give exactly zero variance.
- `StepResult.replicates` is the G8 record (`extra.control.replicates`); `run_replicate_campaign` is a reference loop
  for tests and the G1 contract.

## Decided alone

- "Rejects at α = 0.05" is implemented as p ≤ α.
- Metrics are oriented by `maximize` (all seven D.3 nodes maximise) before the test.
- The engine is harness-free (see open question 1); the E1 side of FIXR3 is
  `RuleLayerController(arm="FIXR3", rule_layer=False)` (A0R unit), which executes every proposal.
