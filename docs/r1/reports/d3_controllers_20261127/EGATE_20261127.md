  clip = 0.05, max_pairs = 8; any other gate is refused), action version `verify:pace`.
- One step: pair j = 0, 1, … runs the candidate at replicate seed j (instance seed for j = 0) and, only if the
  incumbent has no run at seed j, the incumbent too; every run is charged singly through the G8 counter and reused
  incumbent runs are recorded as `charged: false`. After each pair `decide` sees the oriented paired differences so
  far: `commit` → kept; `reject` below 8 pairs → the next pair if the counter can fund it, else discarded
  (`unfundable_pair`); `reject` at 8 pairs → discarded (`max_pairs`).
- First valid trial: kept after one run, no test. Failed candidate run → `failed_invalid`, charged for the runs
  used. Failed incumbent run → discarded (`incumbent_failed`), the run charged and recorded (it counts in the §10
  failure rate through G8). A failed (incumbent, seed) run is never re-run: a later test that reaches that pair ends
  there with discard (`incumbent_failed_earlier`). A step whose first pair cannot be funded is refused before it
  starts (`UnfundableStep`).
- The computed constants of §5.5 hold: commit at 7 pairs needs d ≥ 0.0468 on every pair and costs 14 runs with the
  first trial; at 8 pairs 0.039 commits and 0.038 does not; after one full test the remaining runs cannot commit.

## Decided alone

- Within a pair the candidate runs first; a failed candidate therefore costs no incumbent run.
- A test that reaches a pair whose incumbent run is known to have failed ends **before** running the candidate at
  that seed (the pair can give no difference; §5.5 says the test "ends there").
