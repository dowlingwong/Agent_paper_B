## Corrections after review round 1 (commit `c56e94f4` on `mac-d3-g9-sidecar-20261127`)

- **B1 fixed.** The client no longer re-issues on a timeout. It opens one connection (connect guard
  `connect_timeout_s` only), sends the request once, and waits for the answer with no read time limit, writing a
  progress record (`sidecar_waiting`, polls, waited seconds) every `poll_s` seconds through `on_progress`; deciding
  that a call makes no progress is left to the operator / G1 (R1-NO-TIMEOUT (1)). Test: every call delayed 0.45 s
  beyond a 0.1 s poll — three forecasts, three server calls, no fallback, at least six progress records.
- Minor 1: an answer is a fallback unless it is HTTP 200 with a JSON object carrying a string `digest`; only a
  well-formed answer with another digest is a STOP. Minor 2: the wait record (`sidecar_wait_polls`,
  `sidecar_wait_s`, `failure_rule`) is copied into the E1 decision detail by `D3SidecarRuleController` (a
  `RuleController` subclass; `control.py` unchanged), so it reaches the ledger; tested on a campaign. Minor 3: every
  `OSError` and `http.client.HTTPException` during the exchange is `SidecarLost` (tested: `IncompleteRead`,
  `BadStatusLine`, EHOSTUNREACH, reset, a closed connection). Minor 4: scheme `http` and an explicit port are
  required (`file://localhost`, `https`, a port-less URL are refused). Minor 5: `fallback_stop`'s docstring says it
  counts every epoch and states the caller contract (A5/A6 campaigns of non-sealed attempts). Minor 6:
  `TRACKP_IMAGE_REPO` removed. Failure-rule version is now `d3_sidecar_failures/v2`.
- **Needs the author (level 2), replacing open question 1's row text:** "R1-D3B-SIDECAR-FAILURES: in D.3b a sidecar
  call without an answer is waited for (or issued again with a growing timeout) and never answered by the fallback; a
  sidecar that cannot be reached is an infrastructure failure (§3.1); only an error answer is answered by the
  fallback prior and counts towards the 1 % STOP." Pre-declaration §6 and §10 need one sentence each saying this
  before signing.
