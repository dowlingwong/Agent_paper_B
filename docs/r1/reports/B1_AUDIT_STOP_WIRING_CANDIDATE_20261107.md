# B1 audit STOP notification wiring candidate — 7 November 2026

AI-assisted (Codex). **Candidate for independent review; not accepted and not launch authority.** This follows the unwired component `dc586677` and proposal `e2836214`; those earlier records are historical, superseded only as to whether the component is wired. The unchanged production author note and harness pin do not authorize this branch.

The production B1 runner now creates a nonblocking anonymous pipe before spawning its owned collector. The existing `B1Containment.spawn` passes the writer as a new field of the v2 worker contract; the collector checks its schema, distinct descriptor and nonblocking FIFO writer before work. The parent closes its writer after spawn. The collector uses the explicitly requested `fork` multiprocessing context so audit children inherit the writer; actual node subprocesses use the LocalWorker's `subprocess.run` default close-fds behavior, which still needs Linux verification. A module-level wrapper signals a one-byte STOP before returning an audit exception through the executor. The collector also signals exceptional submission/result/cache failures inside the executor context before its normal shutdown may wait. Normal collector completion sends a distinct byte; it does not itself accept the batch.

A runner-owned monitor polls the read end at a 50 ms interval while the child exists. Upon STOP, unexpected live EOF, malformed data or read failure it marks STOP and invokes the existing owned-cgroup guardian `freeze`; it reports a failure if freeze is not established. The runner checks the monitor before its state save and while the collector runs, requires successful completion notification, collector exit 0 and an empty owned worker cgroup before returning normally, and retains the prior append-only STOP path. Non-B1/DRYRUN jobs do not use the new channel. No process is signaled by this candidate. This is a cooperative process contract; a pipe-shaped FD does not independently prove the peer identity, and same-UID hostile descriptor replacement is outside scope.

The signal traverses the pool result path or audit wrapper and the monitor polls asynchronously. Peers may still write between an audit failure and confirmed cgroup freeze; neither prompt detection nor instantaneous quiescence is asserted. A full pipe, missing writer, unexpected monitor exception, interrupted/short write, failure after the completion byte, child or guardian death, possible inherited FD leakage, error during startup/shutdown, and actual freeze failure require independent review. In particular, inability to write a notification can leave the executor's context manager waiting until the runner notices a channel failure or another watchdog deadline; if another process still holds the writer, EOF may be delayed. No claim is made that arbitrary broken channels or concurrent I/O failures are solved. B1 still requires independent end-to-end review, exact pin, no-deletion descendants, site checks, author gate, tests, and handover.
