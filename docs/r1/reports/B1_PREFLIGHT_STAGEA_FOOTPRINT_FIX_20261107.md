Therefore the 21 model registry placeholders (20 candidates plus the qwen25 anchor) are intentional inputs to that existing resolution path, not numbers to invent or manually replace in the registry. Always-on candidates are skipped under the frozen rule; actual eligibility still depends on the verified site tables.

It passes the resolved anchor to the real server probe; it changes neither the registry, production runner, frozen rule nor author note. A missing, changed, nonpositive, nonfinite, wrong-model or wrong-build row is STOP, not an invitation to measure or select a substitute.
