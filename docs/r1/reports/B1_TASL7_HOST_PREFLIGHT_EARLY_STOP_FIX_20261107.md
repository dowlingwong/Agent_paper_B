# B1 host preflight early-server interruption repair

**Candidate for fresh independent review.** An independent review found that the existing `LlamaServerInstance.start` can have an owned child after `Popen` but before its server record contains `pgid`. The existing `stop()` refuses that empty record, leaving the owned child running. A signal can also arrive during `Popen` before its return value is assigned. This repair is limited to the single-process engineering preflight; no B1 production or pinned-harness code is changed.

During the actual server `Popen` call, the preflight temporarily defers its own handled-signal exception, binds the returned `Popen` object to the instance, then immediately raises on any deferred signal. It does not block or change the child signal mask. It temporarily wraps the existing module's `Popen` only for this serialized preflight server start and restores the binding in `finally`. If the server record is still missing its group, cleanup checks that the still-unreaped direct child has `os.getpgid(pid)==pid`, records that value and calls the existing `LlamaServerInstance.stop()`. A mismatch or inability to inspect is STOP, with no signal to an unidentified group. Signals received during cleanup are recorded without interrupting that cleanup; the preflight returns STOP rather than PASS. Shutdown failure still reports the original error and preserves evidence.

Local test run with pinned harness `a3fedbb`: **11 passed**, pytest base `/private/tmp/paper-b-host-preflight-tests-r7-20261107`. In addition to mocked site checks, two tests start a real owned synthetic sleep server: one injects interruption before server-record construction, another sends a signal during the actual Popen boundary. Each verifies the existing stop path ends that owned process while a separate test-owned session remains alive. A real owned child placed in the wrong group is refused without signalling that group. Another test injects repeated cleanup signals and checks one stop and lock release. No real model, GPU, remote host, author gate or B1 campaign ran. This does not establish behavior after uncatchable SIGKILL, malicious same-UID interference, host GPU quiescence, or actual TASL-7 execution; all site and independent-review prerequisites remain.
