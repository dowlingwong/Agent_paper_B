## Deviations from the brief

1. `RuleController` takes `node_ctx` (the featurizer needs the start files, W and memory mode), plus optional `sigma_cmp` (per edit kind, as offline), `fallback` and `greedy_bin`. `tau_node` is used only for the A6 greedy-bin deployment, in metric units.
2. `RuleController` never verifies (E2 is always `continue`); A1's KG verify (D23) is not part of this controller.
3. For trials without features (trial 1, or no incumbent metric yet) the controller continues; its E2 keep prior is a placeholder that the rule does not use (the first valid metric is kept).
4. One harness commit holds all three hooks rather than one per step.
5. H.4 line includes the trial id and the proposal summary (interpretation, see Q1).
6. The fake llama-server was extended (side queries) and `Sidecar` gained `delay_calls`; `prior_model.chat_client` added for A4/LLM-self against an OpenAI-compatible server.
7. Worker runs and LLM calls in `CampaignUsage` are reconstructed from ledger and events (the `ComputeBudget` is not persisted); `sidecar_calls` counts forecasts the sidecar served (failures are counted in `prior_unavailable`).

3. **Information set for H.7.** All arms are declared `control_view/v1+node_context/v1`: the rule and AWR arms read a function of it (the features), LLM self-control reads the view's canonical payload. Is "identical information set" meant as identical access (as declared) or identical inputs?
4. **Hybrid (proposal).** Revise replaces skip for rule skips and prior skips; the harness does not re-screen the revised proposal at E1, so it always runs; its keep threshold comes from a fresh forecast (for A4 one more charged LLM call). Adopt, or re-screen the revision (needs a harness change)?
5. **Trial budget vs W online.** Skips do not use worker runs but do use trials; with 2W trials a skipping arm may end with unused runs (in the dry run A1/A2 on breast_w used 1 of 3). The offline accounting (22 Oct, option A) credits skips at g; the online trial budget is not decided.
6. **Feature `invalid_so_far`** counts control-plane skips as invalid trials (inherited replay semantics). Split into a separate feature in a featurizer v2 before training on swept data?
7. **A4 template and calibration.** The size-bucket template is fixed and untuned; the isotonic maps need dev data (none fitted yet).
