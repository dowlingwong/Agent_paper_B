# L8 evaluator repair — engineering only

The paired bootstrap expands every template-family draw with multiplicity and
recomputes context-score allocation once per policy on the same resampled rows.
Undefined no-feasible-support draws are counted, not assigned zero. Primary
policy/comparator identifiers are mandatory. `gain_feasible` divides selected
contrast sum by every feasible checkpoint; `gain_selected_only` retains the old
conditional diagnostic. Eligible-population gain has its separate denominator.
The one-step evaluator rejects multiple checkpoints per root and does not infer
unrepresented non-reaching roots. L10 handles its own original-root tree population.

Record validation rejects requested missing outcomes, feasible missing branches,
unmatched repetitions/couplings, inconsistent contexts/masks, and utility-only
outcomes on unavailable actions. Template families, templates and roots cannot
cross any split pair. Sibling variants must carry the same declared family ID;
lineage is not guessed from a name. Selected incremental resource totals are
reported, but realized test costs never determine allocation. No matched-cost
claim is made by this fixed-count evaluator.

Smoke fitting appends feature/action/label tuples together and preserves
fractional repetition means. All scores use the same fixed ridge objective,
features and feasible training units. The matching check inspects fitted
parameter dimensions, regularisation and row counts. Action value fits two
outcome heads versus one for the other learners: its linear contrast class has
the same dimension, but raw fit work differs and is explicitly disclosed.
This is engineering plumbing, not a novelty claim. Streaming thresholds are
fixed on training contexts before calibration. Calibration reports overall
fixture degradation, not a no-fault guarantee. Existing range-two paired bounds,
streaming feasibility masks and joint gain/harm error allocation remain tested.

Validation: 33 control, 28 measurement and 5 release tests pass. The new smoke
is `results/paper_b/smoke_v2_20260926/`, with ENGINEERING_ONLY banners and nine
passing engineering checks. No smoke number is promoted to scientific evidence.
