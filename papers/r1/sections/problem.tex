\section{Problem Formulation}
A governed loop proposes a bounded edit to an incumbent and observes an evaluation if it executes that edit. A controller can use the proposal and available history to decide whether to execute or skip. Execution and model-call budgets are matched in the planned comparisons; the final incumbent is assessed using fresh-seed audits on held-out instances. The in-run record is distinct from this audited outcome.
