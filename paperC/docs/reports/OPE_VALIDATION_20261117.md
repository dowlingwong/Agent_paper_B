# P7 off-policy evaluation on E-SYN

## Design

The budget and strict-null laws have fresh keys, independent Gaussian comparisons and finite budgets. The exact reference evaluates each frozen policy by backward induction over slots and runs left. It averages over rule skips and the discrete proposal-size law and integrates the Gaussian keep gain. Slot 1 is forced execute and keep. OPE uses audited terminal minus start as its sole reward.

Each campaign draws one of the five frozen P4 rungs N0, N1, N2, N3 and N4 crossed with ε ∈ {0, 0.1, 0.25}, with equal probability. At each eligible decision the epsilon draw mixes the rung with a uniform binary action. For OPE, the mixture posterior conditions on the logged history of actions and states. Stochastic actions are replayed from the logged epsilon key. Replay and propensity reconstruction use the same belief view. Deterministic rule steps have probability one.

Each world has 12 independent replicates of 3 disjoint blocks. Each block has 150 training and 50 held-out campaigns. Target policies N0, N1 and N4 were fixed in advance. The two FQE fits update backwards over slot and epoch with a linear ridge regressor or small CPU LightGBM. WDR uses those same fits, marginal mixture likelihood ratios and stepwise normalization with absorbing padding. When no weight survives, the model supplies the remaining prediction.

The point estimate is the mean across block fits. The 95% Student interval uses variation across independent blocks, including refitting variation. Coverage counts use exact binomial limits and the denominator counts complete intervals. The observed bias and coverage are descriptive at this replication count.

## Support

Clusters cross epoch, forecast region (V* ≥ 0.001 at E1, m̂ > 0 at E2) and whether more than half the run budget remains. Each action needs 30 training observations per cluster, and the target needs 200 effective held-out decisions using local action ratios. A shortfall gives insufficient data. This status also applies to a required stage-action cell with no training examples, known zero target-action propensity, or an unfitted stage. Stage-action coverage is checked for both recursive backups and held-out predictions.

The deliberate support removal returns **insufficient data** for N0. Its execute actions have zero propensity in 124 held-out rows.

Value errors include screens with support shortfalls to expose the effect of extrapolation. These runs have a null screen value and an insufficient-data status in the raw results. Local action ESS can be high while the sequential WDR correction has few compatible live trajectories. Late corrections in that case rely heavily on the fitted model. Behaviour-data diagnostics cannot assess states that no behaviour campaign visits.

## Single-decision IPW population contrast

For each holdout campaign, use its first eligible E2 state if it has one. Define a synthetic contrast with reward m̂ for keep and zero for discard. The finite observed-state reference is the mean m̂. The HT estimator uses the history-conditional action propensity. Bias and RMSE are errors against each block's own reference. Fork contrasts use the separate design weights 1/p_select in P6.

## Supported positive control

This follow-up uses the same size and measurement law with 8 slots and 4 runs. It retains all 15 behaviour components and recomputes the N4 threshold table for the shorter horizon from the accepted N4 value law.

Each of 3 disjoint blocks uses 3072 training and 256 held-out roots. The exact N4 value is 0.002268. This check exercises the passing screen path. Its one set of intervals does not estimate coverage.
