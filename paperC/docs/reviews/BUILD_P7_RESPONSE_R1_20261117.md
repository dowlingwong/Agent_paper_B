# Build P7 response to independent review round 1

17 November 2026. **ENGINEERING_ONLY.** [Round 1](BUILD_P7_REVIEW_20261117.md) returned NOT ACCEPTED with two major and two minor findings. The full round-2 suite passed 218 tests with no skips.

| # | Finding | Repair and verification |
|---|---|---|
| 1 | Pooled cluster counts can hide missing FQE training support at a stage | The gate checks every stage-action pair with positive target probability on eligible training backup or held-out states against the eligible training rows at that exact stage. It checks known zero target-action propensity in both splits. `screen_value` is null on any shortfall, and `fqe` records the numerical diagnostic. A regression with 300 skips, 100 executions and sufficient ESS across a single pooled cluster still rejects the unseen stage-2 execute. The raw report records the missing stage-action pairs and their source. |
| 2 | Logged ε action replay was absent | The E-SYN loader checks the logged key and replays the uniform using the recorded node, instance and step. It checks the action against the same probability vector used in the marginal reconstruction. A different logging collector supplies its own keyed `replay_uniform` callback. The regression rejects both a changed E-SYN key and a permitted action with the wrong replayed uniform. |
| 3 | The fit context omitted the selected belief | Context equality now includes node, suite, tier, environment and belief selector. A regression verifies that matching node and environment still fail when fit and holdout use different named forecasts. |
| 4 | The benchmark needed a passing support control | The original two-world sparse-data diagnostics remain. A follow-up uses the budget size and noise law with eight proposal slots and four runs. It retains the 15-component mixture and recomputes N4 from the accepted learned value law. Each of three independent blocks uses 3,072 training and 256 held-out roots. All three pass both FQE screens. The exact N4 value is 0.002268. Linear FQE and both WDR intervals contain it. The LightGBM FQE interval is [0.001662, 0.002220], below the exact value. The supported control provides one interval per method and does not estimate coverage. |

The full rerun preserved every exact value, replicate point and interval, and bias, RMSE and coverage statistic from the original two-world benchmark. All original blocks still carry insufficient-data status. The new positive control exercises the passing path while showing residual approximation error. The deliberate positivity failure continues to flag 124 held-out rows. The generated [report](../reports/OPE_VALIDATION_20261117.md) reproduces byte for byte from the refreshed evidence.
