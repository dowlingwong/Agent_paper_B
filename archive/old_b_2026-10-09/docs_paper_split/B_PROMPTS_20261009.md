# Paper B — prompts for the 9 October author decisions (RUNBOOK §20)

Three prompts, same pattern as Paper A's packs: **Prompt 1** to the agent that
owns Paper B, **Prompt 2** to a reviewing agent in a fresh session, then
**Prompt 3** back to the B agent with the review's location. Written by the
coordinating session (Claude) from RUNBOOK §19–§20 and OPEN_ITEMS §B7–§B8. All
of this is AI-assisted; never describe any of it as human or external review.

**Scope.** Pre-seal work only. The work ends at the D-ATT2 STOP with a diff for
the author. Not part of this pack: the seal, outcome code, the realism run and
any GPU/model or evidence work.

**About Prompt 2.** The contract allows one independent challenge of the
attempt-2 design, and it has been used. Prompt 2 is a *consistency review*: it
checks that the revision implements §20 and changes nothing else. It does not
re-litigate the design's science. If you regard it as a second challenge, skip
it and read the diff yourself at D-ATT2.
